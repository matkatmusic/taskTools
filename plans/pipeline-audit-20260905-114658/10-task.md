# Task 10 plan — per-task workflow.js and steps.json under projectRoot/.taskTools/workflows/N/

This task implements tasks.json 194's base design (per-task workflow file, `meta.name` "Tackle-task N") and the codex-review widening recorded on task 10: 194's own filename convention (`task-N.workflow.js` directly under `.taskTools/workflows/`) is superseded by task 10's own directory convention, `.taskTools/workflows/<N>/workflow.js` and `.taskTools/workflows/<N>/steps.json` side by side, because `steps.json` needs the same per-task isolation `workflow.js` does. Neither file has been generated by any code yet — `generateWorkflow.ts` still hardcodes the single shared plugin path.

Depends on task 12: the `.taskTools/workflows/` gitignore pattern this task's output relies on is added by task 12's `DEFAULT_IGNORE_PATTERNS` change and shipped to every project (new or established) by task 12's `seedGitignore` fix. This task does not touch `seedGitignore` or `DEFAULT_IGNORE_PATTERNS`.
