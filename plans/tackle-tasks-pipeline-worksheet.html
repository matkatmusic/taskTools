Two phases. Everything the skill does is a subdivision of one of these, and nothing gets added until a checkpoint question demands it.

Where this is headed

The two phases expand into four:

  1. Implement the work in a worktree.
  2. Verify the work matches the task.
  3. Merge the work back to the main tree.
  4. Close out the task.

They are not on the diagram yet. A phase earns its box when a question proves the previous phase cannot hand off without it.

The rule

Find every part of that sequence a program can decide, and take it out of the prose in the skill body. Prose is for the parts that need judgment. Everything else is a script that returns an answer.

A checkpoint question is the test: if a script can answer it, a script must answer it.

Checkpoint questions

Each question is a gate between two phases. A phase may only hand off when its questions are answered.
